# Delete after extracting an `erp_*.tgz`

An archive can add and replace files but cannot remove them. Files retired
by a delivered change are listed here with the command that removes them.
Run the block for each delivery you have applied, then clear it from this
file (or delete the file once empty). Nothing here is referenced by code;
leaving a retired file in place only leaves stale text for the next sweep.
