# --- Removed ----------------------------------------------------------------

# pytest-mock: no test module imports it; the suite builds real files in
#     tempfile directories rather than mocking.
# mypy: the project deliberately avoids the typing module and relies on guard
#     clauses for runtime type narrowing, so a static type checker has little
#     to work with and would flag the intended style as errors.
# tox: no tox.ini in the repository.
# black, isort (2026-08-13): never used, and RUNNING either would actively
#     rewrite the codebase against project conventions - isort destroys the
#     length-sorted import ordering, black destroys aligned registry entries
#     and deliberate spacing. Worse than dead weight: a formatter that
#     enforces the wrong style is a loaded gun on the shelf. The [tool.black]
#     config in pyproject.toml went with them.
# flake8 (2026-08-13): never used, and with no config file in the repo its
#     defaults would flag the house style itself (79-char lines, E221
#     multiple-spaces-before-operator on aligned assignments) - pure noise.
# sphinx, sphinx-rtd-theme (2026-08-13): docs/ is plain Markdown with no
#     conf.py; nothing in the repository builds Sphinx documentation.
# pre-commit (2026-08-13): no .pre-commit-config.yaml in the repository,
#     and the hooks it would typically run are the formatters removed above.
#
# All of these date from early scaffolding suggestions; none were adopted.
